# HouseFlow — Property Management System

A full-stack property management application for managing buildings, floors, units, tenants, rent bills, payments, and expenses.

| Layer | Tech |
|-------|------|
| Backend | Spring Boot 4.0.5 · Java 17 · Spring Data JPA · Spring Security |
| Frontend | React 18 · TypeScript · Vite · React Router v6 · Axios |
| Database | MySQL 8.x |
| Build | Apache Maven |

## Database Setup

### 1. Install MySQL 8

Download from https://dev.mysql.com/downloads/mysql/ and install. Default port is `3306`.

### 2. Create the database

Log into MySQL and create the schema:

```sql
CREATE DATABASE rent_system;
```

> Hibernate will auto-create all tables on first boot (`ddl-auto=update`). You do **not** need to create tables manually.

### 3. Configure credentials

Edit `HouseFlow/src/main/resources/application.properties`:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/rent_system
spring.datasource.username=root
spring.datasource.password=YOUR_PASSWORD_HERE
```

Replace `YOUR_PASSWORD_HERE` with your MySQL root password.

### Database Schema (auto-generated by Hibernate)

```
users          id, name, email, phone, password, role
building       id, name, address
floor          id, floor_number, building_id
unit           id, unit_number, rent, floor_id
tenant         id, name, phone, unit_id
rent           id, month, year, base_rent, electricity, water, service_charge, total_amount, status, unit_id
payment        id, amount, month, status, unit_id, tenant_id
rent_bill      id, amount, month, status, unit_id, tenant_id
expense        id, type, amount, date, building_id
```

> **Note:** The `User` entity maps to the table `users` (not `user`) to avoid a conflict with MySQL's built-in system table.

## Backend Setup

### Prerequisites

- Java 17+ — verify with `java -version`
- Maven is bundled via the `mvnw` wrapper — no separate install needed

### Steps

```bash
# 1. Navigate to the Spring Boot project
cd HouseFlow

# 2. Run the application (downloads dependencies on first run)
./mvnw spring-boot:run

# On Windows:
mvnw.cmd spring-boot:run
```

The API will start at **http://localhost:8080**.

You should see Hibernate printing SQL to the console — this confirms the DB connection worked.

### Other Maven commands

```bash
# Compile only (check for errors)
./mvnw compile

# Build a runnable JAR (skip tests)
./mvnw clean package -DskipTests

# Run tests
./mvnw test
```

### application.properties reference

| Property | Purpose |
|----------|---------|
| `spring.jpa.hibernate.ddl-auto=update` | Hibernate creates/alters tables automatically |
| `spring.jpa.show-sql=true` | Prints every SQL query to the console |
| `spring.datasource.driver-class-name` | MySQL JDBC driver class |

## Guidelines — Adding a New Backend Feature

Follow this exact sequence every time you add a new resource (e.g. `MaintenanceRequest`):

### Step 1 — Entity

Create `entity/MaintenanceRequest.java`:

```java
@Entity
@Table(name = "maintenance_requests")   // always explicit, avoid reserved words
@Getter @Setter @NoArgsConstructor @AllArgsConstructor
public class MaintenanceRequest {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String description;
    private String status;          // or use an enum

    @ManyToOne
    @JoinColumn(name = "unit_id")
    private Unit unit;
}
```

> Use `@Table(name = "...")` on every entity to avoid SQL reserved word conflicts.

### Step 2 — DTO

Create `dto/MaintenanceRequestDto.java`. Include only what the API should expose — never expose `password` or internal fields:

```java
@Getter @Setter @NoArgsConstructor @AllArgsConstructor
public class MaintenanceRequestDto {
    private Long id;
    private String description;
    private String status;
    private Long unitId;
}
```

### Step 3 — Repository

Create `repository/MaintenanceRequestRepository.java`:

```java
public interface MaintenanceRequestRepository extends JpaRepository<MaintenanceRequest, Long> {
    List<MaintenanceRequest> findByUnitId(Long unitId);   // add custom queries as needed
}
```

### Step 4 — Service Interface

Create `service/MaintenanceRequestService.java` using **DTOs, not entities**:

```java
public interface MaintenanceRequestService {
    MaintenanceRequestDto create(MaintenanceRequestDto dto);
    List<MaintenanceRequestDto> getAll();
    MaintenanceRequestDto getById(Long id);
    void delete(Long id);
}
```

### Step 5 — Service Implementation

Create `service/impl/MaintenanceRequestServiceImpl.java`:

```java
@Service
public class MaintenanceRequestServiceImpl implements MaintenanceRequestService {

    private final MaintenanceRequestRepository repo;
    private final UnitRepository unitRepo;

    public MaintenanceRequestServiceImpl(MaintenanceRequestRepository repo, UnitRepository unitRepo) {
        this.repo = repo;
        this.unitRepo = unitRepo;
    }

    @Override
    public MaintenanceRequestDto create(MaintenanceRequestDto dto) {
        Unit unit = unitRepo.findById(dto.getUnitId())
                .orElseThrow(() -> new ResourceNotFoundException("Unit not found: " + dto.getUnitId()));
        MaintenanceRequest mr = new MaintenanceRequest();
        mr.setDescription(dto.getDescription());
        mr.setStatus(dto.getStatus());
        mr.setUnit(unit);
        return toDto(repo.save(mr));
    }

    @Override
    public List<MaintenanceRequestDto> getAll() {
        return repo.findAll().stream().map(this::toDto).collect(Collectors.toList());
    }

    @Override
    public MaintenanceRequestDto getById(Long id) {
        return toDto(repo.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Request not found: " + id)));
    }

    @Override
    public void delete(Long id) {
        if (!repo.existsById(id)) throw new ResourceNotFoundException("Request not found: " + id);
        repo.deleteById(id);
    }

    private MaintenanceRequestDto toDto(MaintenanceRequest m) {
        return new MaintenanceRequestDto(m.getId(), m.getDescription(), m.getStatus(), m.getUnit().getId());
    }
}
```

### Step 6 — Controller

Create `controller/MaintenanceRequestController.java`:

```java
@RestController
@RequestMapping("/api/maintenance")
public class MaintenanceRequestController {

    private final MaintenanceRequestService service;

    public MaintenanceRequestController(MaintenanceRequestService service) {
        this.service = service;
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public MaintenanceRequestDto create(@RequestBody MaintenanceRequestDto dto) {
        return service.create(dto);
    }

    @GetMapping
    public List<MaintenanceRequestDto> getAll() { return service.getAll(); }

    @GetMapping("/{id}")
    public MaintenanceRequestDto getById(@PathVariable Long id) { return service.getById(id); }

    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void delete(@PathVariable Long id) { service.delete(id); }
}
```

### Rules to always follow

- **Never use entity directly in a controller** — always go through DTO
- **Always throw `ResourceNotFoundException`** for missing records (not `null` returns)
- **Never add `@PathVariable` routes that conflict** — if you need `/{id}` and `/{name}`, use `/name/{name}` for the string version
- **Add `@Table(name = "...")` on every new entity** — Hibernate default names sometimes conflict with SQL reserved words
- **Add CORS origin** in `AppConfig.java` if a new frontend origin is needed

## Guidelines — Adding a New Frontend Page

Follow this exact sequence every time you add a new page (e.g. for `MaintenanceRequest`):

### Step 1 — Add the TypeScript type

In `src/types/index.ts`, add:

```typescript
export interface MaintenanceRequest {
  id: number;
  description: string;
  status: string;
  unitId: number;
}
```

### Step 2 — Add the API client

In `src/api/client.ts`, add one line:

```typescript
export const maintenanceApi = crud<MaintenanceRequest>('/maintenance');
```

### Step 3 — Create the page

Create `src/pages/Maintenance.tsx`. Use `ResourcePage<T>` for the standard list/create/delete pattern:

```tsx
import { useState, useEffect } from 'react';
import ResourcePage from '../components/ResourcePage';
import { maintenanceApi, unitApi } from '../api/client';
import type { MaintenanceRequest, Unit, FormField } from '../types';

const columns = [
  { key: 'id',          label: 'ID' },
  { key: 'description', label: 'Description' },
  { key: 'status',      label: 'Status' },
  { key: 'unitId',      label: 'Unit ID' },
];

export default function Maintenance() {
  const [units, setUnits] = useState<Unit[]>([]);

  useEffect(() => {
    unitApi.getAll().then(setUnits).catch(() => {});
  }, []);

  const formFields: FormField[] = [
    { key: 'description', label: 'Description', type: 'text', fullWidth: true },
    { key: 'status',      label: 'Status',      type: 'select',
      options: [{ value: 'OPEN', label: 'Open' }, { value: 'CLOSED', label: 'Closed' }] },
    { key: 'unitId',      label: 'Unit',        type: 'select',
      options: units.map(u => ({ value: u.id, label: `Unit ${u.unitNumber}` })) },
  ];

  return (
    <ResourcePage<MaintenanceRequest>
      title="Maintenance"
      subtitle="Track unit maintenance requests"
      columns={columns}
      formFields={formFields}
      emptyForm={{ description: '', status: 'OPEN', unitId: '' }}
      fetchAll={maintenanceApi.getAll}
      create={maintenanceApi.create as (d: Record<string, string | number>) => Promise<MaintenanceRequest>}
      remove={maintenanceApi.remove}
    />
  );
}
```

> If your form fields don't need data from other resources (no dropdowns), skip the `useEffect` and just define `formFields` as a plain constant.

### Step 4 — Register the route

In `src/App.tsx`, add the import and route:

```tsx
import Maintenance from './pages/Maintenance';

// inside <Route path="/" element={<Layout />}>
<Route path="maintenance" element={<Maintenance />} />
```

### Step 5 — Add the sidebar link

In `src/components/Layout.tsx`, add to the `navItems` array:

```typescript
{ to: '/maintenance', icon: '🔧', label: 'Maintenance' },
```

Place it under the appropriate section (`Property`, `People`, `Finance`, or `Developer`).

### Step 6 — Add to API Explorer

In `src/pages/ApiExplorer.tsx`, add a new group to the `GROUPS` array:

```typescript
{
  name: 'Maintenance', icon: '🔧', accent: '#64748b',
  endpoints: [
    { id: 'mr-list',   method: 'GET',    path: '/api/maintenance',      description: 'List all requests' },
    { id: 'mr-get',    method: 'GET',    path: '/api/maintenance/{id}', description: 'Get request by ID', paramKey: 'id' },
    { id: 'mr-create', method: 'POST',   path: '/api/maintenance',      description: 'Create a request',  bodyHint: '{ "description": "Fix tap", "status": "OPEN", "unitId": 1 }' },
    { id: 'mr-delete', method: 'DELETE', path: '/api/maintenance/{id}', description: 'Delete a request',  paramKey: 'id' },
  ],
},
```

### Rules to always follow

- **Use `ResourcePage<T>`** for standard CRUD pages — don't duplicate the list/modal/delete logic
- **Fetch parent resources in `useEffect`** and pass them as `options` in `formFields` — keep it reactive so the dropdown updates if data changes
- **Add `.catch(() => {})` on dependency fetches** — if Buildings fails to load, the Floors page should still render (just with an empty dropdown)
- **Never hardcode IDs** — always fetch the list and let the user pick from a dropdown
- **Add status badge rendering** for any `status` or `role` column:
  ```tsx
  { key: 'status', label: 'Status', render: (row) => <span className={`badge badge-${row.status}`}>{row.status}</span> }
  ```
- **Money fields** should use `step: '0.01'` on the `FormField`
- **Maintain the type cast pattern** on `create`:
  ```tsx
  create={myApi.create as (d: Record<string, string | number>) => Promise<MyType>}
  ```

## Common Errors & Fixes

| Error | Cause | Fix |
|-------|-------|-----|
| `Access to XMLHttpRequest blocked by CORS` | Backend not allowing the frontend origin | Check `AppConfig.java` — add your origin to `allowedOrigins` |
| `Communications link failure` | MySQL not running or wrong credentials | Start MySQL, check `application.properties` password |
| `Table 'rent_system.X' doesn't exist` | Schema not created | Run `CREATE DATABASE rent_system;` in MySQL |
| `NoSuchBeanDefinitionException` for a service | Missing `@Service` on the impl class | Add `@Service` to the `*ServiceImpl` class |
| `could not extract ResultSet` | Entity field doesn't match column | Check entity field names vs actual DB columns |
| `Cannot DELETE or UPDATE a parent row` | FK constraint — child records exist | Delete child records first (e.g. delete Floors before Building) |
| Frontend blank page | JS error in console | Open browser DevTools → Console tab, fix the reported error |
| `net::ERR_CONNECTION_REFUSED` on API calls | Backend not running | Start the backend with `./mvnw spring-boot:run` |
| TypeScript build error `unused variable` | `noUnusedLocals` is enabled | Remove the unused variable or prefix with `_` |
